
## راه‌اندازی روی GitHub
1. این پوشه را به‌صورت یک مخزن جدید روی GitHub آپلود کنید (شاخه‌ی `main`).
2. **اندروید:** تب *Actions* ← `Build Android APK` ← *Run workflow*. بعد از چند دقیقه فایل `CarControl-debug.apk` در *Artifacts* است (بدون نیاز به امضا نصب می‌شود).
   برای APK امضاشده (release) این Secrets را بسازید: `ANDROID_KEYSTORE_B64` (فایل jks به‌صورت base64)، `ANDROID_KEYSTORE_PASSWORD`، `ANDROID_KEY_ALIAS`، `ANDROID_KEY_PASSWORD`. با ساخت تگ مثل `v1.0.0` فایل‌ها در *Releases* هم قرار می‌گیرند.
3. **وب‌اپ آیفون:** *Settings ← Pages ← Source = GitHub Actions*. سپس workflow به‌نام `Deploy Web App` اجرا می‌شود. آدرس نسخه‌ی وب `https://<نام‌کاربری>.github.io/<نام‌مخزن>/` است. در سافاری: Share ← *Add to Home Screen*.
4. **iOS نیتیو (اختیاری):** `Build iOS` فقط درستیِ کامپایل را بررسی می‌کند. برای نصب روی آیفون به حساب Apple Developer نیاز است (Secrets: `IOS_CERT_P12_B64`, `IOS_CERT_PASSWORD`, `IOS_PROFILE_B64`, `IOS_TEAM_ID`).

## ساز و کار توکن
- فریمور هیچ کاربری را از قبل نمی‌شناسد. اولین بار، اپ (وصل به وای‌فای دستگاه) `کد فعال‌سازی` (`ACTIVATION_CODE` در فریمور) را به `/api/pair` می‌فرستد.
- اگر کد درست بود، دستگاه با `esp_random()` یک توکن تصادفی ۱۲۸ بیتی (۳۲ حرف hex) می‌سازد، در حافظه‌ی فلش ذخیره می‌کند و به اپ برمی‌گرداند. اپ آن را روی گوشی نگه می‌دارد.
- از آن به بعد هر درخواست باید هدر `X-Token: <token>` داشته باشد (یا `?t=`)؛ بدون توکن معتبر پاسخ `401` می‌آید. فقط `/api/ping` و `/api/pair` بدون توکن هستند.
- ۵ بار کد اشتباه ← ۶۰ ثانیه قفل. حداکثر ۲۰ توکن؛ با ۲۱امین، قدیمی‌ترین حذف می‌شود. گزینه‌ی «خروج» در اپ توکن همان گوشی را حذف می‌کند (`/api/unpair`).
- دیگر نیازی به MAC نیست (مشکل MAC تصادفی گوشی‌ها حل شد). MAC فقط به‌عنوان «آخرین دستگاه شناخته‌شده‌ی این توکن» ثبت می‌شود تا سیستم امنیتی قطع آنتن بفهمد کاربر حاضر است؛ اگر MAC عوض شد، با اولین درخواست بعدی خودکار به‌روز می‌شود. «کاربر حاضر است» یعنی: درخواست معتبر در ۴۵ ثانیه‌ی اخیر، یا گوشیِ دارای توکن هنوز به وای‌فای دستگاه وصل است.
- کنترل از راه دور توکن جداگانه‌ای دارد: همان `Device Token` موجود MQTT (مسیر `car/<token>/…`).

## API (همه GET و پاسخ JSON)
| مسیر | کار |
|---|---|
| `/api/ping` | تشخیص دستگاه + معتبر بودن توکن (بدون توکن) |
| `/api/pair?code=` | فعال‌سازی و دریافت توکن (بدون توکن) |
| `/api/state` | **یک درخواست** به‌جای چهار درخواست قبلی: خروجی‌ها، سیگنال وای‌فای، GSM، GPS، امنیت |
| `/api/config` | همه‌ی تنظیمات (فقط هنگام باز کردن صفحه‌های تنظیمات) |
| `/api/toggle?pin=` · `/api/weak?enabled=` · `/api/name?pin=&name=` · `/api/threshold?value=` | صفحه‌ی اصلی |
| `/api/ap?ssid=&password=&ip=` | نقطه‌ی دسترسی (ذخیره و ریبوت) |
| `/api/sim` · `/api/apn` | SIM800: APN، شماره‌ها، فرمان‌های SMS، امنیت |
| `/api/gps` · `/api/mqtt` | GPS و محدوده‌ی امن؛ سرور MQTT |
| `/api/unpair` | حذف توکن همین گوشی |

## نکته‌های مهم
- **اتصال مستقیم** فقط در اپ اندروید/iOS کار می‌کند. نسخه‌ی وب (آیفون) به‌دلیل قانون مرورگر (HTTPS ← HTTP ممنوع) فقط **از راه دور** (MQTT روی WebSocket) کنترل می‌کند.
- بروکر `smartcarlock.ir` باید **WebSocket (ترجیحاً wss)** را فعال داشته باشد. نشانی آن را در «تنظیمات برنامه» وارد کنید (پیش‌فرض نمونه: `wss://smartcarlock.ir:8084/mqtt` — پورت واقعی را از ادمین سرور بپرسید).
- تنظیمات (AP، SIM800، GPS، MQTT) فقط در حالت مستقیم قابل تغییر است؛ در حالت راه دور فرمان‌های `lock/unlock/alarm/location/toggle` موجودند.
- اندروید: برنامه خودش به وای‌فای دستگاه می‌چسبد (بدون اینترنت هم کار می‌کند). گوشی ممکن است خودش از وای‌فای «بدون اینترنت» خارج شود؛ گزینه‌ی *Switch to mobile data automatically / Auto network switch* را خاموش کنید.
- iOS: بار اول اجازه‌ی «Local Network» را بدهید.
